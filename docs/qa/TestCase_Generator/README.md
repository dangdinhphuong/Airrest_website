# TestCase_Generator

Công cụ sinh Test Case tự động, dùng để chuyển SRS/tài liệu nghiệp vụ thành file Test Case Excel theo chuẩn công ty.

## Nội dung

- `tool_v2/` — mã nguồn công cụ (prompts, luật đối chiếu, script sinh/kiểm tra test case, hướng dẫn sử dụng). Xem `tool_v2/README.md.docx` và `tool_v2/huong-dan/HUONG-DAN-SU-DUNG.md.docx` để biết cách vận hành.

## Liên quan

- Test Case đầu ra nên được đặt vào [`../../03_TestCases/`](../../03_TestCases/) theo quy ước `TC_{Menu}.xlsx`.
